[BP-01] BLOG POST OUTLINE GENERATOR:
"Create a comprehensive SEO outline for a blog post targeting the keyword '[KEYWORD]'. The target reader is [AUDIENCE]. Include: H1 (include exact keyword), meta description (155 chars), 5-7 H2 sections each with 2-3 H3 subheadings, FAQ section (5 questions targeting 'People Also Ask'), and word count recommendation per section. The post should rank by thoroughly answering search intent."

[BP-02] INTRODUCTION WRITER (5 styles):

Style 2: Story-based intro
Style 3: Question-based intro
Style 4: Bold claim intro
Style 5: "Before vs After" intro

[BP-03] SECTION WRITER:
"Write the H2 section '[SECTION HEADING]' for a blog post about [TOPIC]. Target reader: [AUDIENCE]. Include: [NUMBER] key points, at least one specific example or data point, a practical tip, and a natural transition to the next section. Length: [300-500] words. SEO keyword to include naturally: [KEYWORD]."

[BP-04] CONCLUSION + CTA:
"Write a conclusion for a blog post about [TOPIC] that: summarizes the [3-5] main points without being repetitive, gives one clear actionable next step, and includes a call to action for [subscribe to newsletter / download free resource / check out related post]. Friendly, motivating tone."

[BP-05] FAQ SECTION:
"Create a FAQ section for a blog post about [TOPIC]. Include 5-7 questions that people commonly search and that target 'People Also Ask' boxes on Google. For each question: write a direct answer in 40-80 words using the question keyword naturally."
