MASTER EVENT CHECKLIST (by timeline):

12 MONTHS OUT:
□ Define event objectives and success metrics
□ Set budget and get approval
□ Research and book venue
□ Determine event format (in-person/virtual/hybrid)
□ Set date (check for conflicts)
□ Identify key speakers/entertainment
□ Start vendor research

6 MONTHS OUT:
□ Sign venue contract
□ Book keynote speaker(s)
□ Select and book AV company
□ Book catering (if separate from venue)
□ Hire event photographer/videographer
□ Create event website/registration page
□ Begin sponsor outreach
□ Launch early-bird registration

3 MONTHS OUT:
□ Finalize agenda and run of show
□ Confirm all vendors in writing
□ Send save-the-dates to confirmed speakers
□ Launch full marketing campaign
□ Build attendee communication calendar
□ Arrange accommodations if needed
□ Plan transportation/shuttle if needed

1 MONTH OUT:
□ Final headcount to all vendors
□ Create seating chart (if applicable)
□ Finalize attendee list
□ Send detailed logistics to speakers
□ Create event day kit
□ Confirm all vendor arrival times
□ Print/prepare all signage

1 WEEK OUT:
□ Final venue walkthrough
□ Pack event supplies box
→ Tape, scissors, markers, extension cords, power strips
→ Name badges, lanyards, pens
→ Registration list (printed + digital backup)
→ Speaker tech requirements confirmed
→ Emergency contact list printed

EVENT DAY:
□ Arrive 2 hours before doors open
□ Check all AV/tech
□ Confirm catering setup
□ Brief all staff/volunteers
□ Have backup plans accessible

POST-EVENT:
□ Thank-you emails within 24 hours
□ Speaker thank-you notes
□ Vendor final payments
□ Post-event survey
□ Budget reconciliation
□ Event debrief meeting
□ Report to stakeholders

[VI-03] AV/Tech inquiry: "We need AV support for a [EVENT TYPE] for [X] guests. Setup includes: [stage, screens, mics, livestream, etc.]. Can you share your packages and availability?"
